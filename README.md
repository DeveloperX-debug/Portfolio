# Prem Saraf — Portfolio

A static portfolio site built with HTML, CSS, and vanilla JavaScript. It introduces Prem Saraf, highlights selected projects and skills, and links to GitHub and LinkedIn.

## View the site

Open `index.html` in a browser, or visit the published site:

https://developerx-debug.github.io/Portfolio/

## Project files

- `index.html` — page content and project links
- `styles.css` — layout, visual styles, and responsive rules
- `app.js` — reserved for site interactions; the current page does not require JavaScript
- `*.png` — project thumbnails

## Run locally

No build step or package installation is needed. Open `index.html` directly in a browser or serve this folder with any static file server.

The `requirements.txt` file is retained for compatibility with existing tooling; this static portfolio has no Python dependencies.
